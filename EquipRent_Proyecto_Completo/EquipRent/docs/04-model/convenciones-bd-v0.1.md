# Convenciones de Base de Datos — EquipRent v0.1 (Clase 05)

## Nombres
- Base: `equiprent` · Schema: `equiprent` · Rol de laboratorio: `equiprent_admin`
- Tablas: snake_case, singular (`unidad_equipo`)
- Columnas: snake_case (`codigo_unidad`)
- PK: `<tabla>_id`; constraint `pk_<tabla>`
- FK: columna `<tabla_referida>_id`; constraint `fk_<tabla>_<referida>`
- UNIQUE: `uq_<tabla>_<columna>`
- CHECK: `ck_<tabla>_<regla>`
- Índices: `idx_<tabla>_<columna>`

## Tipos candidatos
- Identificador técnico: BIGINT GENERATED BY DEFAULT AS IDENTITY
- Texto corto: VARCHAR(n) con n justificado
- Texto amplio: TEXT
- Importes: NUMERIC(12,2)
- Fecha: DATE (adquisición, vigencia de tarifa)
- Instante con hora: TIMESTAMPTZ (reservas, entregas, auditoría)
- Booleanos: BOOLEAN
- Estados: VARCHAR(20) + CHECK
- Detalle flexible de auditoría: JSONB

## Regla de equipo
Toda excepción debe quedar justificada. Nunca FLOAT para dinero ni VARCHAR(255) por costumbre.
