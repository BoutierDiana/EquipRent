# Glosario v0.1 — EquipRent

| Término | Significado inicial |
|---|---|
| Equipo | Modelo o producto genérico en el catálogo que define las características comunes y la tarifa base (ej. "Taladro Bosch 500W"). |
| Unidad Física | Objeto real, individual e irrepetible (identificado por número de serie o código patrimonial) que se entrega, se daña y se devuelve. |
| Disponibilidad | Condición dinámica calculada que asegura que una unidad física no tiene solapamientos de reservas ni mantenimientos en un rango de fechas solicitado. |
| Cliente | Persona natural o jurídica que contrata el servicio, asume la custodia del equipo y deja el depósito de garantía. |
| Reserva | Compromiso temporal formalizado que aparta una o varias unidades físicas para un cliente en fechas delimitadas. |
| Entrega | Evento operativo que formaliza el momento exacto en que el cliente asume la custodia física de la unidad. |
| Devolución | Evento que registra el retorno de la custodia de la unidad a la empresa, marcando el fin del período de uso. |
| Inspección | Peritaje técnico obligatorio ejecutado sobre una unidad retornada para verificar su condición, desgaste u horómetro. |
| Daño | Hallazgo negativo o avería detectada durante la inspección que justifica la retención del depósito y el bloqueo del activo. |
| Mantenimiento | Estado que indica la indisponibilidad temporal de una unidad física por ingreso a taller para revisión o reparación. |
| Depósito | Garantía de respaldo (dinero u otro medio) retenida temporalmente para responder por posibles daños o retrasos. |
| Tarifa | Regla de negocio o valor acordado utilizado para calcular el importe económico del tiempo de alquiler. |
| Auditoría | Registro histórico inmutable para trazar excepciones autorizadas y cambios de estado críticos en la operación. |

> Este glosario es v0.1. Los significados pueden refinarse cuando aparezcan nuevas reglas, pero los cambios deberán quedar documentados en el repositorio.
