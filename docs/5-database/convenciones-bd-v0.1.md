# Convenciones de Base de Datos — EquipRent v0.1

## Nombres
- Tablas: minúsculas, singular, snake_case (ej: `cliente`, `unidad_equipo`)
- Columnas: minúsculas, snake_case (ej: `fecha_inicio`, `codigo_inventario`)
- PK: `id` (columna técnica autogenerada en cada tabla)
- FK: `<tabla_referenciada>_id` (ej: `equipo_id`, `cliente_id`)
- UNIQUE: `uq_<tabla>_<campo(s)>` (ej: `uq_unidad_equipo_codigo_inventario`)
- CHECK: `ck_<tabla>_<regla>` (ej: `ck_reserva_fechas`)
- Índices: `ix_<tabla>_<campo>` (se definirán cuando existan consultas frecuentes que lo justifiquen)

## Tipos candidatos
- Identificador técnico: `BIGINT GENERATED BY DEFAULT AS IDENTITY`
- Texto corto (códigos, nombres): `VARCHAR(n)` con n ajustado al dato real
- Texto amplio (descripciones, observaciones): `TEXT`
- Importes/decimales exactos (tarifas, depósitos): `NUMERIC(p,s)`
- Fecha (sin hora, ej. fecha de adquisición): `DATE`
- Instante con hora (reservas, entregas, devoluciones): `TIMESTAMPTZ`
- Booleanos: `BOOLEAN`
- Estados: `VARCHAR(20)` + `CHECK` con el dominio cerrado de valores

## Regla de equipo
Toda excepción a esta convención debe quedar justificada en `modelo-fisico-v0.1.md` o en
`decisiones-integridad-v0.1.md` (Clase 04), indicando el motivo de negocio.
