# Decisiones técnicas y de producto

Esta carpeta almacenará decisiones relevantes del proyecto (ADR o notas equivalentes) para EquipRent.

Cada decisión importante deberá indicar:
1. Contexto.
2. Problema o decisión.
3. Alternativas consideradas.
4. Decisión tomada.
5. Consecuencias conocidas.

En la Clase 01 todavía no se registra una decisión arquitectónica formal porque aún no se ha iniciado el diseño técnico detallado.
